# Бавовна — сайт ресторану (одна сторінка, українською)

Статичний сайт: HTML, CSS і трохи JavaScript. Без збирачів і npm.

## Як подивитися локально
```
cd "Bavovna final "
python3 -m http.server 8777
```
Потім відкрийте http://localhost:8777/ (відео й форма працюють коректно лише через сервер).

## Що де лежить
- `index.html` — вся сторінка (hero, розріз, маніфест, графік, меню вражень, три речі, шеф, нагорода, меню, вечори, сертифікати, бронювання, візит)
- `assets/css/style.css` — кольори, шрифти, відступи (змінні на початку), `fonts.css` — підключення шрифтів
- `assets/js/main.js` — шапка, розріз, анімації, вкладки меню, форма
- `assets/img`, `assets/video`, `assets/fonts` — медіа й шрифти
- `_source/` — оригінали фото й відео, НЕ для публікації

## Що замінити перед запуском
- Фото страв лежать у `assets/img/dishes/` (взяті з меню Choice). Для сніданків фото є лише в гранoли: додайте решту й пропишіть `data-img` у відповідних `.sd`.
- Форма бронювання працює на Netlify Forms (`data-netlify`). Поза Netlify вона покаже запасний варіант із телефоном і поштою.
- Кнопки «Придбати» ведуть до форми з форматом «Подарунковий сертифікат». Якщо в ресторана є сторінка оплати, підставте її посилання.
- Додайте `canonical` і абсолютні адреси для `og:image`, коли буде домен.

## Публікація
Netlify: перетягніть папку (без `_source`) на netlify.com/drop або підключіть GitHub.
