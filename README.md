# Бавовна — сайт ресторану (українською)

Статичний сайт: HTML, CSS і трохи JavaScript. Без збирачів і npm. Є одна серверна функція (Netlify) для заявок у Telegram.

## Як подивитися локально
```
cd "Bavovna final "
python3 -m http.server 8777
```
Потім відкрийте http://localhost:8777/. Шляхи в HTML кореневі (`/assets/...`), тому відкривати файли подвійним кліком не можна. Функція заявок працює лише на Netlify (або через `netlify dev`); на простому сервері форма покаже запасний варіант із телефоном.

## Сторінки
- `/` — головна: hero, графік, тизери розділів, шеф, нагорода, бронювання, візит із картою
- `/degustatsiine-menu/` — дегустаційне меню
- `/menu/` — меню à la carte (закуски, основні, десерти, сніданки)
- `/shefskyi-stil/` — шефський стіл
- `/sertyfikaty/` — сертифікати (перемикач «Онлайн / Подарункова картка»)

Кожна сторінка має свої title, description, H1 і canonical. Шапка, футер і `<head>` повторюються в кожному файлі, тому змінюючи меню, правте всі п'ять `index.html`.

## Заявки в Telegram
Форма бронювання тихо надсилає заявку на `/.netlify/functions/booking` (файл `netlify/functions/booking.js`), а функція пересилає її в Telegram-чат. Гостю нічого натискати в Telegram не треба. Атрибута `data-netlify` більше немає, Netlify Forms не використовується.

Налаштування:
1. У @BotFather створіть бота й візьміть токен.
2. Додайте бота в чат ресторану й дізнайтеся `chat_id`.
3. У Netlify: Site settings → Environment variables → додайте `TELEGRAM_BOT_TOKEN` і `TELEGRAM_CHAT_ID`.
4. Задеплойте. Токен лишається на сервері й не потрапляє в браузер.

Кнопки «Замовити сертифікат» ведуть на `/?format=...#book`, і форма відкривається з уже вибраним форматом.

## Що замінити перед запуском
- `ДОМЕН` у canonical, `og:url`, `og:image`, `twitter:image`, JSON-LD, `robots.txt` і `sitemap.xml`: замініть на справжній домен. З кореня проєкту (macOS):
  `grep -rl "ДОМЕН" --include=*.html --include=*.xml --include=*.txt . | xargs sed -i '' 's#ДОМЕН#ваш-домен.ua#g'`
- У блоці «Про нас писали» на головній стоять назви видань текстом. Замініть їх на SVG-логотипи й додайте посилання на статті (у HTML є коментар `TODO`).
- Рейтинг додайте, коли будуть справжні відгуки (`aggregateRating` у JSON-LD).
